# 가정 사항 기록

계획서 12장 기본값 외에, 작업 중 새로 정한 내용을 적어요. 확정되면 이 문서와 코드를 함께 고쳐 주세요.

## Phase 1

| 항목 | 가정 | 이유 / 바꾸는 곳 |
|---|---|---|
| 프로젝트 위치 | 저장소 루트를 `kanfa-web/` 프로젝트 루트로 사용 | 저장소에 이 프로젝트만 있음 |
| 프레임워크 버전 | Next.js 16 (App Router), React 19, Tailwind CSS 4 | 작업 시점 최신 안정판. Tailwind 4는 설정 파일 대신 `app/globals.css`의 `@theme`에 토큰을 둔다 |
| 시연 기준 날짜 | `2027-04-20 09:00 (KST)` | 목업 대회가 2027년이라 실제 오늘로 계산하면 접수 상태·남은 날이 맞지 않음. `lib/clock.ts`의 `DEMO_TODAY` |
| 대회 날짜 | 시범 대회 2027-03-13(토), 개막전 2027-05-15(토), 2차전 2027-07-10(토) | 시연 기준 날짜에 시범=종료, 개막전=접수 중, 2차전=접수 예정이 되도록 배치. `data/events.json` |
| 접수 기간 | 개막전 4/1 10:00~5/2 18:00, 2차전 6/1 10:00~6/27 18:00 | 대회 7일 전 출발조 배정·취소 마감보다 앞서 접수가 끝나도록 |
| 정원·신청 인원 | 개막전 720명 중 583명, 2차전 900명, 시범 300명(마감) | 출발조 30명 × 오전·오후 시간대 기준의 임의 값 |
| 시범 대회 장소 | 대전 한밭체육관 | 계획서에 장소가 없어 임의 지정 |
| 시범 대회 부문 | 개인(성인·어르신)만 운영 | 시범 운영이라 팀 부문 제외 |
| 개인 부문 데이터 | `Division`에 선택 필드 `course`를 추가해 개인(성인)·개인(어르신)을 두 항목으로 둠 | 개인 부문은 코스별 참가비가 달라 `type`만으로 구분 불가 |
| 기록 데이터 | 구간 기록(`splits`) 6개의 합 = 전체 기록(`totalSec`), 결승 구간 기록에 유연성 단축이 이미 반영됨 | 표시 계산을 단순하게 하기 위함 |
| 성장상 기준 | 시범 대회 결과의 `improvementSec`은 대회 전 사전 측정 레이스 대비 향상 폭으로 가정 | 시범 대회는 '직전 대회'가 없음 |
| 장소 데이터 | 센터·파트너 이름과 주소는 모두 예시이며 주소 끝에 "(예시 주소)"를 붙임 | 실제 기관·업체로 오해하지 않도록 |
| [참가 신청] 버튼 연결 | `/events`(대회 일정)로 이동 | 신청은 대회를 먼저 골라야 함 |
| 헤더 메뉴 외 페이지 | 신청 조회·훈련 장소 찾기·공지사항은 모바일 메뉴와 바닥글에 둠 | 헤더 가운데 메뉴는 계획서 4.1의 6개만 유지 |
| 모바일 메뉴 기준 폭 | 1280px 미만에서 햄버거 메뉴 | 글자 크게(20px)를 켜도 데스크톱 헤더가 넘치지 않도록 |
| 글꼴 | Pretendard Variable(동적 서브셋), Barlow Condensed 600·700(라틴) — 모두 npm 패키지로 자체 제공 | 외부 CDN 의존 없이 정적 내보내기 |
| 보조 색 | 글자용 진한 변형 추가: 필드 그린 글자 `#1F7A50`, 보조 글자 `#4A5772`, 오류 `#B42318` | 원래 필드 그린(#2F9E6B)·미스트 그레이는 흰 배경 위 글자 대비 4.5:1 미달 |
| 문의처 | "KANFA 운영사무국 000-0000-0000 · help@kanfa.example (자리표시)" | 계획서상 자리표시 |
| 공지사항 데이터 | 시안 공지 3건(`data/notices.json`) | P2 화면용 |

## Phase 2

| 항목 | 가정 | 이유 / 바꾸는 곳 |
|---|---|---|
| 트랙 히어로 | 안쪽 레인이 1레인(1등급), 점은 4레인을 따라 시계 반대 방향(육상 트랙 방향)으로 약 4초 동안 한 바퀴 | "4등급이라면 4번 레인"이라는 예시로 콘셉트를 보여주기 위함. `components/TrackHero.tsx` |
| 트랙 위 구간 표시 | 성인 코스 6개 구간의 체력요소 이름을 트랙 안쪽 잔디에 표시 | 성인·어르신 코스는 구간 구성이 달라 히어로에는 대표로 성인 코스를 씀 |
| [내 등급 확인 방법] 버튼 | `/how-to#measure`(참여 방법의 '내 등급 확인 방법' 영역)로 이동 | 별도 페이지가 계획서에 없음 |
| 이름의 뜻 풀이 | K=KSPO(국민체육진흥공단), A=Arena(겨루는 무대), N=for National(모든 국민을 위한), F=Fitness(체력), A=Award(인증과 시상) | 계획서의 영문 이름을 글자별로 풀어 씀 |
| 체력왕 선발대회 설명 | "측정 결과가 뛰어난 사람을 뽑는 대회"로 서술, 연도·회차는 표기하지 않음 | 연혁 확인 전. `app/about/page.tsx` |
| 2인·4인 부문 코스 | 팀원마다 자기 나이에 맞는 코스(성인·어르신)를 뛴다고 안내 | 계획서에 팀 부문 코스 규칙이 없음. Phase 3 신청서에서도 같은 규칙 적용 예정 |
| 구간별 동작 설명·도움말 | 국민체력100 측정 방법을 바탕으로 레이스 규칙에 맞게 새로 작성 | 계획서에는 규칙만 있음. 한국스포츠과학원 검증 후 확정 필요. `data/courses.json` |
| 동작 그림 | 구간 번호와 측정항목 이름을 넣은 자리표시 그림 | 실제 일러스트는 별도 제작 |
| 출발조 예시 | "30대 · 여성 · 4등급, 10:20 출발" | 이해를 돕기 위한 예시 |
| 홈 자주 묻는 질문 3개 | 등급이 없어도 참가 / 체력이 약해도 참가 / 레이스 기록과 등급 | 첫 방문자가 가장 궁금해할 질문으로 선정 |
