# 가정 사항 기록

계획서 12장 기본값 외에, 작업 중 새로 정한 내용을 적어요. 확정되면 이 문서와 코드를 함께 고쳐 주세요.

## Phase 1

| 항목 | 가정 | 이유 / 바꾸는 곳 |
|---|---|---|
| 프로젝트 위치 | 저장소 루트를 `kanfa-web/` 프로젝트 루트로 사용 | 저장소에 이 프로젝트만 있음 |
| 프레임워크 버전 | Next.js 16 (App Router), React 19, Tailwind CSS 4 | 작업 시점 최신 안정판. Tailwind 4는 설정 파일 대신 `app/globals.css`의 `@theme`에 토큰을 둔다 |
| 시연 기준 날짜 | `2027-04-20 09:00 (KST)` | 목업 대회가 2027년이라 실제 오늘로 계산하면 접수 상태·남은 날이 맞지 않음. `lib/clock.ts`의 `DEMO_TODAY` |
| 대회 날짜 | 시범 대회 2027-03-13(토), 개막전 2027-05-15(토), 2차전 2027-07-10(토) | 시연 기준 날짜에 시범=종료, 개막전=접수 중, 2차전=접수 예정이 되도록 배치. `data/events.json` |
| 접수 기간 | 개막전 4/1 10:00~5/2 18:00, 2차전 6/1 10:00~6/27 18:00 | 대회 7일 전 출발조 배정·취소 마감보다 앞서 접수가 끝나도록 |
| 정원·신청 인원 | 개막전 720명 중 583명, 2차전 900명, 시범 300명(마감) | 출발조 30명 × 오전·오후 시간대 기준의 임의 값 |
| 시범 대회 장소 | 대전 한밭체육관 | 계획서에 장소가 없어 임의 지정 |
| 시범 대회 부문 | 개인(성인·어르신)만 운영 | 시범 운영이라 팀 부문 제외 |

| 기록 데이터 | 구간 기록(`splits`) 6개의 합 = 전체 기록(`totalSec`), 결승 구간 기록에 유연성 단축이 이미 반영됨 | 표시 계산을 단순하게 하기 위함 |
| 성장상 기준 | 시범 대회 결과의 `improvementSec`은 대회 전 사전 측정 레이스 대비 향상 폭으로 가정 | 시범 대회는 '직전 대회'가 없음 |
| 장소 데이터 | 센터·파트너 이름과 주소는 모두 예시이며 주소 끝에 "(예시 주소)"를 붙임 | 실제 기관·업체로 오해하지 않도록 |
| [참가 신청] 버튼 연결 | `/events`(대회 일정)로 이동 | 신청은 대회를 먼저 골라야 함 |
| 헤더 메뉴 외 페이지 | 신청 조회·훈련 장소 찾기·공지사항은 모바일 메뉴와 바닥글에 둠 | 헤더 가운데 메뉴는 계획서 4.1의 6개만 유지 |
| 모바일 메뉴 기준 폭 | 1280px 미만에서 햄버거 메뉴 | 글자 크게(20px)를 켜도 데스크톱 헤더가 넘치지 않도록 |
| 글꼴 | Pretendard Variable(동적 서브셋), Barlow Condensed 600·700(라틴) — 모두 npm 패키지로 자체 제공 | 외부 CDN 의존 없이 정적 내보내기 |
| 보조 색 | 글자용 진한 변형 추가: 필드 그린 글자 `#1F7A50`, 보조 글자 `#4A5772`, 오류 `#B42318` | 원래 필드 그린(#2F9E6B)·미스트 그레이는 흰 배경 위 글자 대비 4.5:1 미달 |
| 문의처 | "KANFA 운영사무국 000-0000-0000 · help@kanfa.example (자리표시)" | 계획서상 자리표시 |
| 공지사항 데이터 | 시안 공지 3건(`data/notices.json`) | P2 화면용 |

| 2인·4인 부문 코스 | 팀원마다 자기 나이에 맞는 코스(성인·어르신)를 뛴다고 안내 | 계획서에 팀 부문 코스 규칙이 없음. Phase 3 신청서에서도 같은 규칙 적용 예정 |

| 동작 그림 | 구간 번호와 측정항목 이름을 넣은 자리표시 그림 | 실제 일러스트는 별도 제작 |

## Phase 3

| 항목 | 가정 | 이유 / 바꾸는 곳 |
|---|---|---|
| 남은 자리 계산 | 목업의 `capacity - applied`에서 이 브라우저에서 신청한 인원(취소 제외)을 뺀 값 | 서버가 없어 다른 사람의 신청은 반영할 수 없음. `lib/event.ts`의 `seatsLeft` |
| 정원 마감 | 접수 중이어도 남은 자리가 0이면 '마감'으로 보여주고 신청을 막음. 팀 인원보다 남은 자리가 적으면 그 부문을 고를 수 없음 | 계획서 4.7 "정원이 다 찼으면 신청 버튼을 막는다" |
| 중복 신청 | 같은 대회에 같은 휴대폰 번호(팀원 포함)로 낸 '신청 완료' 상태 신청이 있으면 막음. 취소한 신청은 제외 | 취소 후 다시 신청할 수 있어야 함 |
| 신청 조회 | 접수번호와 휴대폰 번호 뒤 4자리가 일치하면 조회. 팀 신청은 팀원 누구의 번호로도 조회 가능 | 팀원도 자기 신청을 확인할 수 있게 |
| 접수번호 | `KANFA-{대회 연도}-{4자리 순번}`, 이 브라우저 안에서 1부터 차례로 매김. 취소한 번호는 다시 쓰지 않음 | 서버가 없어 전체 순번을 알 수 없음 |
| 생년월일 입력 | 8자리 숫자(19900315) 한 칸. 하이픈·점이 섞여도 받음 | 달력 선택보다 어르신·대리 입력이 쉬움 |
| 코스 판단 | 개인·팀 모두 참가자마다 대회일 기준 만 나이로 코스를 정하고, 2단계에서 '위 코스로 참가할게요' 체크로 확인받음 | 계획서 4.7은 개인 부문만 언급. 팀원도 코스를 알아야 함 |
| 개인 부문 참가비 | 첫 참가자의 코스로 성인 50,000원 / 어르신 30,000원 | 개인 부문은 코스별 참가비가 다름 |
| 건강 문진 | 신청 한 건에 한 번 답함. 팀 신청은 "팀원 중 한 명이라도 해당하면 '예'" | 팀원별 문진은 화면이 너무 길어짐. 실제 서비스에서는 팀원별 문진 권장 |
| 안전 서약 | 4단계 '안전 수칙을 지키겠습니다' 체크와 6단계 '안전 서약' 동의를 모두 받음 | 계획서 4.7에 두 곳 모두 있음 |
| 등급 조회 목업 | 끝자리 0~5: 1~6등급(시연 기준일에서 25~150일 전 측정), 6~7: 이력 없음, 8~9: 420일 전 측정(대회일 기준 1년 경과) | 계획서 5.2. 유효기간은 대회일 기준으로 판단 |
| 등급 다시 불러오기 | 등급을 불러온 뒤 휴대폰 번호를 바꾸면 다시 불러와야 함 | 다른 사람 등급이 남는 것을 막음 |
| 출발조 배정 표시 | 대회 7일 전 전까지는 "대회 7일 전(5월 8일) 배정 예정"으로 표시 | 시연 기준일(4월 20일)에는 배정 전 |
| 취소 가능 기간 | 시연 기준일이 대회일 7일 전 날짜보다 앞이거나 같으면 취소 가능 | 계획서 12장 |
| 캘린더 파일 | 대회일 오전 9시~오후 5시 일정으로 .ics 생성 | 출발 시간이 정해지기 전이라 대회장 운영 시간으로 넣음 |
| 입장용 QR | 접수번호로 무늬만 만든 자리표시 그림(스캔 안 됨) | 계획서 4.7 "QR 자리표시" |
| 띠 배너 | 시연 기준일(2027년 4월 20일)을 함께 표시 | 실제 날짜와 다른 '남은 날'을 이해하도록 |

## Phase 4

| 항목 | 가정 | 이유 / 바꾸는 곳 |
|---|---|---|
| 시범 대회 출발조 | 성인 코스는 성별 × 등급대(1~3 / 4~6), 어르신 코스는 남녀·1~6등급 한 묶음 | 시범 대회 출발 시간표(`data/events.json`)와 같은 기준. `lib/results.ts`의 `heatKey` |
| 결과 데이터 | 40건을 다시 만들어 성별마다 1~6등급이 고르게 돌아가도록 함(성인 26 · 어르신 14) | 계획서 5.2 "코스·성별·등급이 고르게". 생성 규칙은 결정적 |
| 순위표 | 코스를 먼저 고르고, 성별·연령대·등급으로 거른 뒤 기록 빠른 순으로 순위를 매김 | 성인·어르신은 코스가 달라 기록을 함께 비교할 수 없음 |
| 성장상 | `improvementSec`(사전 측정 레이스 대비 빨라진 시간)이 큰 순서. 기록이 없는 사람은 빠짐 | 시범 대회에는 직전 대회가 없음(Phase 1 가정) |
| 시연용 종료 대회 신청 | `data/demoApplications.json`에 두 건: KANFA-2027-0901(뒤 4자리 0901, 성인 4등급, 배번 A007), KANFA-2027-0902(뒤 4자리 0902, 어르신 4등급, 배번 S032). 신청 조회에서 함께 찾음 | 종료된 대회는 신청할 수 없어 리포트를 볼 방법이 없음 |
| 신청-기록 연결 | 참가자에 `bib`(배번)을 붙여 결과와 연결 | 실제로는 대회 당일 배번 배정 시 연결 |
| 체력 분석 리포트 | 구간 기록을 같은 코스·같은 등급 참가자 평균과 비교(남녀 함께). 평균보다 가장 느린 구간으로 운동처방을 고름 | 계획서 4.8 "같은 등급 평균과 비교" |
| 운동처방 문구 | 체력요소 9개에 추천 운동·방법을 시안으로 작성 | 한국스포츠과학원·체력인증센터 검증 전. `lib/results.ts`의 `PRESCRIPTIONS` |
| 차트 색 | 나 = 트랙 블루, 같은 등급 평균 = 앰버 `#E39A2D`. 값 라벨을 막대 끝에 표시하고 [표로 보기] 제공 | 팔레트 검사 통과. 앰버는 배경 대비 3:1 미만이라 값 라벨·표로 보완 |
| 체력증진교실 연결 | 리포트의 [가까운 체력증진교실 찾기]는 `/places?kind=center`(체력인증센터만)로 이동 | 체력증진교실은 체력인증센터에서 운영한다고 가정 |
| 기록 공개 전 | 결과가 없는 참가자는 "대회가 끝나고 3일 안에 올려 드려요" 안내 | 운영 기준 미정 |
